# AI Glasses 智能眼镜管理平台

面向电脑端浏览器的 V0.1 本地演示原型。设备、AI 事件、识别结果和统计均为模拟数据；摄像头未接入视频。项目不连接硬件、后端或模型服务。

## 本地运行

**最简单的方式（Windows）：** 安装 Node.js 22.12 或更高版本（https://nodejs.org ，选 LTS），然后双击项目根目录的 `启动项目.bat`。第一次运行会自动安装依赖（需要联网，约 1–3 分钟），之后会自动打开浏览器。使用过程中不要关闭弹出的命令行窗口。

也可以手动执行。需要 Node.js 22.12+ 和 npm，在项目根目录执行：

```powershell
npm ci
npm run dev
```

打开终端打印的本地地址，默认是 `http://127.0.0.1:5173`。开发服务只监听本机。

```powershell
npm run typecheck
npm run build
npm run preview
```

`npm run build` 先检查 TypeScript，再生成 `dist/`；`npm run preview` 可在本机查看构建结果。

## 登录与授权演示

打开后台会先进入登录页。可以点击「填入演示超管凭据」后登录，也可以使用以下公开演示账号：

| 用户名 | 演示口令 | 初始角色与状态 |
| --- | --- | --- |
| `admin01` | `AigDemo-admin01` | 超级管理员，已启用 |
| `analyst01` | `AigDemo-analyst01` | AI 分析师，已启用 |
| `reviewer01` | `AigDemo-reviewer01` | 数据审核员，已启用 |
| `viewer01` | `AigDemo-viewer01` | 只读观察员，默认停用，可由超管启用 |

1. 在登录页选择「注册演示账号」，提交新用户名和演示口令。用该账号尝试登录，可以看到待审批提示。
2. 在同一浏览器打开同一地址的第二个标签页，用 `admin01` 登录。进入「管理员中心」，处理申请、选一个普通角色并批准。
3. 回到第一个标签页用新账号登录，比较可见菜单和可用操作。比如分配「只读观察员」后，事件结论可看但不可编辑。
4. 在超管的标签页编辑新账号权限，给「审核识别结果」设置「允许」并保存。新账号可编辑事件结论，但仍看不到样本页。改为「禁止」后，结论立即恢复只读；停用账号会结束其会话。管理员中心会留下变更日志。

账号、权限与日志留在使用同一地址（含端口）的浏览器中，登录状态保存在当前标签页。注册的口令只保存带盐的验证值。这套机制只演示流程，不能保护真实数据。请勿填写真实密码。

## 第一轮演示

1. **实时监控**：切换单画面和四宫格、选择设备、查看模拟 AI 结果及近期事件，进入设备详情。
2. **设备管理**：按设备编号或名称搜索，按状态筛选，查看模拟电量、网络和最近通信。
3. **单设备详情**：查看摄像头占位、设备状态和历史调用；锁定一个 AI 功能，确认其他模拟事件仍可进入事件列表。
4. **其他模块**：可按账号权限访问 AI 运行分析、AI 事件中心、样本审核、数据集管理、模型监控、管理员中心和系统设置。事件详情、候选样本录入和审核、数据集浏览、账号审批与授权提供演示交互；完整数据集维护、模型诊断和后端配置留待后续。

模拟事件默认静止。超管在「系统设置 → 自动刷新模拟数据」开启后，每 14 秒追加一条模拟事件；退出超管会话时暂停，重新加载页面后恢复默认关闭。实时监控和 AI 运行分析共用调用统计（模拟基线加本轮新增），历史抽样图不随刷新变化。事件与候选样本共用识别质量结论，人工修正和收录资格单独保存；审核修改保存在当前浏览器标签页中。实际运行截图位于 `artifacts/screenshots/`。

界面采用借鉴苹果设计原则的视觉层（`src/styles/glass-theme.css`，在 `src/main.tsx` 最后引入；删除这一行 import 即可回到旧样式）：以字号和留白区分层级，克制用色（保留项目自己的品牌蓝），胶囊按钮，以及参考 Liquid Glass 的玻璃材质。玻璃用在侧栏、顶栏控件、Dock 和抽屉这些浮在内容上方的导航层；窗口内容使用更厚的磨砂底，表格使用不透明白底，保证阅读。侧栏、顶栏胶囊和 Dock 的边缘折射由 `src/hooks/useLiquidGlass.ts` 按元素实际尺寸生成位移贴图实现，Dock 浮在窗口上方，内容从下方滚过时会在边缘弯折（Chromium 内核浏览器可见，其他浏览器保留普通毛玻璃）。窗口按钮使用项目自己的简洁样式；区块标题、数字卡片不再使用图标方块，页面说明文字保留给读屏软件。

「系统设置 → 界面与显示 → 透明效果」默认开启，也可选关闭或跟随系统。选择跟随系统时，如果操作系统开启了“减少透明度”（Windows：设置 → 个性化 → 颜色 → 透明效果 关闭），界面会使用不透明底色。

「系统设置 → 界面与显示 → 系统主题」可以选择浅色、深色或跟随系统。默认使用浅色，所选主题保存在当前浏览器，重新打开仍会沿用。

左侧导航、底部 Dock、「单画面／四宫格」和样本审核的识别质量控件支持玻璃气泡拖选：用鼠标按住一项，拖到目标选项后松开；在选项之外松开会取消。连续点击时，气泡可以直接转向下一项。使用键盘时，可用方向键移动焦点，再按 Enter 确认。

从左侧导航可在同一工作台打开多个模块，新窗口默认铺满工作区；点击已经打开的模块会切换到原窗口。设备和事件详情按编号分别打开，所以可以与列表、样本审核或另一条详情并排对照。

在有足够空间的工作区，拖动标题栏可以移动窗口，拖动任意一条边或四个角可以自由调整宽高；拖到工作区的左、右、上、下边缘可以占半屏，拖到四个角可以占四分之一屏；也可以点标题栏的「窗口布局」按钮，从八种位置里直接选择。吸附到某个位置时，原来占用这块区域的窗口会变回浮动。空间不够的布局会显示为不可选。浮动窗口右上角的「等比缩放窗口」会打开一条贴着标题栏的小滑块，保留窗口宽高比。用标题栏最小化后，从底部 Dock 恢复，窗口会保留筛选和滚动位置。窄窗口一次显示一个页面，通过 Dock 切换。刷新浏览器时只重开地址栏对应的页面。系统启用「减少动态效果」时，窗口会直接收起和恢复；启用「减少透明度」时，窗口使用不透明底色。

项目使用 React、TypeScript、Vite、Tailwind CSS、React Router、Lucide 和 Recharts。页面和共享组件在 `src/pages/` 与 `src/components/`，Mock 数据与读取入口分别在 `src/mocks/` 和 `src/services/`。原始视觉参考保留在 `UIDesignPlanDraft/`。
